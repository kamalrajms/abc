## react intro

    What is React?
  

  
    1) React is a JavaScript library (not a framework) developed by Facebook (Meta) for building user interfaces (UIs), especially Single Page Applications (SPAs).

    2) It helps developers build reusable UI components that update efficiently when data changes.

    Instead of reloading a whole webpage when something changes, React updates only the parts of the UI that need to change.

    -------
    Why do we need React?

	It makes UI development faster, cleaner, and more efficient.

	Provides a better user experience with smooth updates without page reloads.

## useState() & access input

        useState is a react hook that allows you to add state (data that can change over time)
        to a function components

        Normally, in js function ,variables disappear after the function runs,
        but with useState hook , react remember values b/w re-render.


        syntax:

            const[state,setState]=useState(initialValue)

            const[count,setCount]=useState(55)

            state -- the current value of the state variables
            setState -- a function that update the state.
            initialValue -- the starting value of the state.

## Routing in react. && nexted routing

    Routing means navigation b/w pages in a web Applications without refreshing browser.

    In traditional webpage,clicking a link reloads the whole page.

    In react (Single page Application) Routing lets us changethe view without reloading.



            better performance 
            Smooth user experience
            Control over navigation without server request

    commend:npm install react-router-dom

    basic structure:

    <<BrowserRouter>
        <Routes>
            <Route path:"/homepage" element={<Home/>}/>
            <Route path:"/Aboutpage" element={<About/>}/>
            <Route path:"/servicepage" element={<service/>}/>
        </Routes>
    </BrowserRouter>

    BrowserRouter:

        It is the main wrapper component for routing in react app.
        it enables navigation using the browser URL.
        without ,it routing will not work

    Routes:

        It contains all the  <Route/> component.
        It tells react router which component to show for the path.
        Only one rout will match and render at a time

    Route:

        Defines a specifif URL path and component .
